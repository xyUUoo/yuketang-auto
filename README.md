# 雨课堂自动刷课工具（Yuketang Auto Study）

**Playwright + 系统 Edge + PySide6 桌面控制台** 的雨课堂网课自动学习工具：
视频自动播放、课件按「未读标记消失即翻页」，支持暂停 / 继续 / 结束控制、视频与课件分开刷、最多 3 窗口并行、
进度看板（视频 / 课件分别完成度）。可最小化浏览器窗口，脚本在后台继续运行。

## 功能特性

- **独立 Edge profile 登录态复用**：首次扫码登录一次，之后自动复用，无需重复登录
- **跨课程自动遍历**：自动解析"我听的课"，默认只刷**最新学期**的课程（`--all-semesters` 可刷全部）
- **刷课模式**：完整播放每个【视频 + 计分 + 未完成】条目，并逐页学习每个【课件】条目，播完/翻完自动切下一条、自动切下一门
  - 实时轮询播放状态判定完成（`ended` 或进度 ≥ 总时长-1s），另有超时兜底
  - 暂停自动恢复播放；卡进度自动点"继续观看"
  - 播完刷新未完成列表，已刷条目自动消失，**不重复刷**
- **课件逐页学习**：按大纲页码翻页，**当前页「未读」标记一消失就翻下一页**（服务端记阅读约 1 秒）
  - 大纲驱动：点大纲缩略图第 N 页 → 等该页 `未读` 标记消失 → 立刻下一页，典型 2 秒/页（原固定停留 10 秒/页）
  - 读不到大纲/未读标记时自动退回按钮 → 图标 → 键盘（→/PageDown/空格）→ 滚动试探翻页
  - 翻页判据：未读标记消失 → 学习进度 x/y → 页码 a/b → 页面截图指纹（纯图片 PPT 也判得出）
  - 收尾多轮校验：前端消标记比服务端落库快，隔 8 秒回看并补刷掉队页，直到「进度满格 + 未读 0 页」连续两次通过
  - `--dwell` 现在是**每页最长等待**（不再是固定停留），等不到标记消失才用满；页内嵌视频仍会等播完
  - 卡住时自动输出页面结构诊断到日志，便于定位适配
- **刷课类型可选**：`--types video,courseware`（默认两者都刷），本轮只刷视频就写 `video`
- **检查模式**：快速遍历所有课程的目标列表并刷新进度记录，**不点击、不播放**
- **无任务课程自动跳过**：刷课时跳过已确认无视频任务的课程；未检查过的课现场检查一次，
  5 次重试加载失败也按无任务记录，之后直接跳过，直到下次检查状态重新评估
- **未完成类型分布**：左侧课程表格显示每门课的未完成类型分布（视频 / 课件 / 作业 / 开放型作业等）
- **浏览器内核级静音**（`--mute-audio`）：页面 JS 无法取消，静音不失效
- **进度记录**：`progress.json` 自动记录每门课 总目标 / 剩余 / 是否已刷完
- **进度看板按类型展示**：表格分「视频完成度 / 课件完成度 / 未刷 / 状态 / 类型分布」，
  无该类型目标的列显示 `0 / 0`；只刷一类时另一类的剩余不会被清零
- **控制台双按钮**：「开始刷网课视频 / 开始刷网课课件」分开跑，控制栏按钮文字完整显示不截断
- **并行刷课**（`--parallel 2/3`）：最多 3 门课程同时刷，动态任务池调度
  - 同一课程不会被重复领取；其他窗口能看到谁在刷哪门
  - 某门刷完自动去领下一门没人在刷的；没有可刷课程时窗口自动关闭
  - 并行自动复制登录态 profile，多个窗口均免扫码
- **暂停 / 继续**：一键暂停播放与翻页，再点继续恢复
- **结束**：彻底关闭刷课脚本与所有刷课用的 Edge 浏览器，清理残留进程
- **自动更新**：启动后自动检查 GitHub 新版本，弹窗三选（下载更新 / 下次提醒 / 忽略此版本）
  - 下载进度 cmd 风格显示在日志栏（百分比 + 已下载/总量 + 速度）
  - 下载完成自动重启安装为新版；忽略后直到下个版本发布才再次提醒
  - 检查更新过程写入日志栏，失败也能看到原因
- **设置（代理）**：可配置检查更新/下载使用的代理地址（直连 → 代理兜底），
  没网的环境也能收到更新提示
- **首次运行提示**：第一次点"开始刷课"时弹窗建议先"检查状态"，避免误判
- **完成弹窗 + Windows 通知**：全部结束后深色弹窗汇总（各课程状态一览）
- **健壮性**：单门课程异常自动跳过继续，不会中断整个任务

## 环境要求

- Windows + 系统安装 **Microsoft Edge**
- Python 3.11+（仅源码运行时需要；直接用 exe 免装 Python）

## 快速开始

```bat
:: 1. 创建虚拟环境并安装依赖
py -3.11 -m venv .venv
.venv\Scripts\pip install -r requirements.txt

:: 2. 首次运行：浏览器弹出后扫码登录一次（之后自动复用登录态）
.venv\Scripts\python auto.py
```

> 使用系统 Edge（`channel="msedge"`），**无需** `playwright install` 下载浏览器。

## 使用方式

### 命令行

```bat
:: 刷全部课程（完整播放）
run.bat
:: 或
.venv\Scripts\python auto.py

:: 只刷指定课程
.venv\Scripts\python auto.py --course 分布式数据库技术

:: 只看进度记录
.venv\Scripts\python auto.py --status

:: 每门课程最多刷 3 条
.venv\Scripts\python auto.py --max-lessons 3

:: 检查模式（快速遍历，不播放）
.venv\Scripts\python auto.py --quick

:: 3 门课程同时刷
.venv\Scripts\python auto.py --parallel 3
```

### 桌面控制台（推荐）

双击 `gui.bat` 打开 PySide6 控制台：

- **进度看板**：课程表格 + 完成度进度条 + 状态（刷课中 / 检查中 / 等待中 / 已刷完 / 无任务）
  + 每门课的**未完成类型分布**列
- **实时日志**：自动滚动显示运行日志（含检查更新、类型分布、跳过记录等）
- **开始刷课**：完整播放模式（可选每门条数、并行窗口数 1~3）
- **检查状态**：快速遍历刷新进度记录（不播放）
- **暂停 / 继续**：暂停后视频停住、翻页停住、进度不计，再点继续恢复
- **结束**：终止脚本并关闭所有刷课用的 Edge 浏览器
- **设置**：修改检查更新/下载使用的代理地址
- **自动更新**：启动后自动检查，弹窗三选下载 / 下次提醒 / 忽略

## 直接下载程序（免装 Python）

在 [Releases](../../releases) 下载最新版：

| 文件 | 说明 |
|---|---|
| `yuketang-gui.exe` | **单文件完整版**（控制台 + 刷课核心全部打包在内，约 83MB） |

下载后放进一个空文件夹，双击 `yuketang-gui.exe` 即可使用。
首次运行会自动打开 Edge，扫码登录一次，之后自动复用登录态（登录信息只保存在本地 exe 旁边的 `edge_profile/` 文件夹，不会上传）。

## 命令行参数

| 参数 | 说明 |
|---|---|
| `--course 名称` | 只刷指定课程（模糊匹配） |
| `--dwell 秒` | 课件每页**最长等待**秒数（默认 10，视频用不到）：未读标记消失即翻页，等不到才用满 |
| `--types video,courseware` | 刷哪些类型，默认视频+课件都刷；只刷视频写 `video`，只刷课件写 `courseware` |
| `--max-lessons N` | 每门课程最多刷几个条目（0=全部） |
| `--headless` | 完全无头模式（不显示浏览器窗口） |
| `--all-semesters` | 刷全部学期的课程（默认只刷最新学期） |
| `--quick` | 检查模式：遍历目标列表，不点击不播放 |
| `--status` | 只查看进度记录，不刷课 |
| `--parallel 1~3` | 同时刷课的课程数（动态任务池，最多 3） |

## 目录结构

```
yuketang_auto/
├── auto.py             # 主脚本（刷课核心）
├── gui.py              # PySide6 桌面控制台（单文件双模式入口）
├── gui.bat             # 控制台启动入口
├── run.bat             # 命令行刷课入口
├── bump_version.py     # 版本号自动递增
├── build.bat           # PyInstaller 打包脚本
├── requirements.txt    # 依赖清单
├── edge_profile/       # Edge 登录态（自动生成，勿提交）
├── progress.json       # 进度记录（自动生成，勿提交）
├── tasks.json          # 并行任务池（自动生成，勿提交）
├── settings.json       # 设置（代理等，自动生成，勿提交）
└── log.txt             # 运行日志（自动生成，勿提交）
```

## 运行流程

```
首页 → 我听的课 → 逐门课程（最新学期）→ 点"未完成"
     → 解析【视频+计分+未完成】待办 → 逐个播放到结束
     → 刷新列表（已刷条目消失）→ 播完自动切下一门
     → 无视频任务的课程自动跳过（下次检查重新评估）
     → 全部完成 → 深色弹窗汇总 + Windows 通知
```
